## 知识库取舍

- **名字不走 History + 神名**：模块名、程序集名都是 `Usus`；页面 owner 仍按宿主规则推为 `HistoryUsus`。
- **经验是数据，不是指令**（2026-11-03 定）：之前把经验做成一条条 MCP 指令是错的。总线上只有 `usus.kb.*` 几条检索指令，经验本身是 `z-经验库/` 下的文件；加经验不发版。
- **长期数据留在托管内**（2026-11-03 定）：经验正文是长期维护的资产，放本仓 `z-经验库/`、纳入 git（小于 100MB 不走 LFS）；运行区只放可再生的索引与缓存，删掉能从正文重建。二者不能混放。
- **一条经验一个文件**：切块就按条目切，一条只讲一件事，检索时不会把一条经验切成两半。格式见 `z-经验库/README.md`。
- **AI 加经验就是写文件**：不靠 `kb.add` 指令；AI 用 `diana.z.write path=2026-045/z-经验库/<分类>/<编号>-<标题>.md` 新建或修改（写即提交），人直接在 `z-经验库/` 里改，写完跑 `usus.kb.check` 看格式和下一个编号。每次取用前列一次文件比对指纹（路径、大小、修改时间），变了就重建索引，没变的文件正文不重读。✔
- **编号只增不复用**：下一个编号按文件名取最大值，格式不合的文件也占号。✔
- **结构**：`b-Code/Usus/Knowledge/` 是纯检索核心（条目解析、关键词索引、快照），**不许引用宿主**，将来可原样抽成独立包；`UsusModule` 把它投成 `usus.kb.*`。
- **混合检索**：工程资料里型号、标准号、数值多，纯向量检索找不准，所以关键词（BM25）与语义向量各出一批再合并。0.2.0 只有关键词检索：中文按连续汉字二元组切，字母数字整段保留（`HGH20CA`、`M8` 原样命中），标题与标签各按 3 倍加权。✔ 语义检索第二步接本地 Ollama 的嵌入模型（候选 bge-m3、Qwen3-Embedding），数据不出本机，向量索引落运行区。
- **检索结果必带出处**：返回条目 id、标题、文件相对路径、命中片段，AI 引用经验时要能回指到文件。
- **经验库只经 `diana.z.*` 读**（0.3.0，2026-11-07 定）：z 级文件夹只在源码区机器上、从不迁移，模块可以迁到任意机器，所以缺省位置是 z 地址 `2026-045/z-经验库`，经 `diana.z.tree` / `diana.z.read` 读，不认本机路径。没装 Diana 时检索明确失败并说原因。`usus.kb.root` 可改成别的 z 地址；写成本机绝对目录只给测试排障。0.2.0 存进设置的旧缺省（本机绝对路径）自动按新缺省读。✔
- **指令检索不在这里做**：「按语义找指令」属于 Portunus 的 `find`，将来可以和本模块共用嵌入服务，但索引分开。

## 工程约定

- **改动只进 dev 工作区。** 先 `vulcan.dev.start`，在 F 盘工作区里改，`submit` 送审热装，批准后 `finish`。直接改主树最后没法 finish。
- **只用统一契约（宿主 6.0.0 起编译期强制）。** 宿主给的只有一条总线和一个上下文：`ExecuteAsync` / `InvokeAsync` / `RequestConfirmation`，登记口只能 `Register`。数据目录、运行方式走 `context.Environment`，宿主位置问 `vulcan.host.info`。不引用 `HistoryVulcan.Services`，不拼 `%AppData%`。✔
- **版本三处一致**：`<模块>Version.props`、`module.manifest.json`、`project.manifest.json`。不一致时宿主静默跳过整个模块。✔
- **`ModuleInfo.ModuleName` 显式写死模块名**：缺省值是程序集名，同时也是指令域。✔
- **页面 owner = `History` + 首字母大写的指令域**，与模块名无关；对不上整页被 Aurora 静默拒收。✔
- **界面协议指令**（`<域>.ui.describe / actions / data`）只读并带 `HiddenReason`。✔
- **宿主程序集 `Private=false`**：部署时由宿主提供；测试工程反过来 `Private=true`。
- **`.gitattributes` 必须有 `z-Publish/** binary`**：否则快照换行，finish 热装 SHA 不符。✔
- **`.ps1` 必须带 UTF-8 BOM**；`SHA256SUMS` 与 manifest 不能带 BOM。✔
- **模块内不定义 `[ComImport]`**：可卸载装载上下文不能做 COM 互操作。✔
- **不读已移除的上下文成员**（`context.Settings` / `context.DataDirectory`）。宿主日志用 `context.Log`，过程用 `CommandContext.Progress`。✔
- **不跨仓 ProjectReference**，文档里也不写指向别的仓的相对链接。✔
- **外部程序的 API 以真机标定为准。** 文档与实测不符时，把证据写进本文件，用测试钉住实测组合。
- 手写 JSON 用编辑工具整文件写，不要经 shell heredoc（反斜杠会被吃掉）。
